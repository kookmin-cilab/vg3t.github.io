# VG3T project website

Project page for the research by Junho Kim and Seongwon Lee, Kookmin University.

Copied from [Junho Kim's published project page](https://junho2000.github.io/vg3t.github.io/) with Junho Kim's permission, provided by Seongwon Lee. This repository contains the static website and its assets.

The original layout, research content, figures, videos, author links, and template credit are retained. The original Google Analytics configuration was removed. The unused interpolation preloader is guarded so this page does not request absent template frames.
